# 官方入口索引

[技术偏好](./preferences.md) 中每项候选对应的官网与文档入口，供核验版本、平台支持和实际应用时查找。按偏好表的领域顺序排列。

## 使用说明

- 这里只记录入口，不复制文档内容；版本、API 与兼容性以入口指向的当前文档为准，按 [选型流程](../SKILL.md) 的核验要求读取。
- 优先使用宿主可用的文档工具检索对应库；需要直接打开页面时从下表进入。
- 链接于 2026-10-20 核对可访问。失效或迁移时更新本表，不在其他文件复制链接。
