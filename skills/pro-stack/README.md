# pro-stack

为桌面软件、移动应用、网站/Web 应用及其配套后端，结合需求和随附技术偏好提供选型建议。技术栈已确定或仅进行日常开发时，继续遵循项目现有决策。

编写或维护 Skill、独立 MCP server/工具/插件、agent 配置、提示词、命令行脚本和工具链不属于本流程。是否触发取决于本次交付物和决策需求，具体边界见 [SKILL.md](./SKILL.md)。

## 内容索引

| 入口 | 内容 |
|---|---|
| [SKILL.md](./SKILL.md) | 触发条件、选型流程、证据核验与协商边界。 |
| [技术偏好索引](./references/README.md) | 独立维护的技术候选、场景原则与官方文档入口。 |
| [行为用例索引](./evals/README.md) | 用例文件、覆盖范围与验证方式。 |

## 使用

- “用 pro-stack 分析这个新网站的技术栈，先给建议。”
- “比较两条桌面技术路线，重点看平台支持、性能与维护成本。”

Skill 直接读取随附偏好并结合项目需求提出建议。技术选型流程、偏好内容与官方文档入口分别以 `SKILL.md`、`references/preferences.md` 和 `references/docs.md` 为准。
