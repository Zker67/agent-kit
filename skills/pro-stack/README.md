# pro-stack

根据项目需求和随附技术偏好，提供技术选型、框架比较与架构建议。技术栈已确定或仅进行日常开发时，继续遵循项目现有决策。

## 内容索引

| 入口 | 内容 |
|---|---|
| [SKILL.md](./SKILL.md) | 触发条件、选型流程、证据核验与协商边界。 |
| [技术偏好索引](./references/README.md) | 独立维护的技术候选与场景原则。 |
| [行为用例索引](./evals/README.md) | 用例文件、覆盖范围与验证方式。 |

## 使用

- “用 pro-stack 分析这个新项目的技术栈，先给建议。”
- “比较两条桌面技术路线，重点看平台支持、性能与维护成本。”

Skill 直接读取随附偏好并结合项目需求提出建议。技术选型流程与偏好内容分别以 `SKILL.md` 和 `references/preferences.md` 为准。
