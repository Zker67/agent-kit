# 行为用例索引

[evals.json](./evals.json) 保存 6 个行为用例：

| ID | 覆盖场景 |
|---|---|
| 1 | 高性能、标准 UI 的 Windows 桌面选型。 |
| 2 | 直接依据偏好进行博客选型。 |
| 3 | 选型遵循现有界面复用与数据约束。 |
