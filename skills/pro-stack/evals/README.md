# 行为用例索引

[evals.json](./evals.json) 保存 14 个行为用例：

| ID | 覆盖场景 |
|---|---|
| 1 | 高性能、标准 UI 的 Windows 桌面选型。 |
| 2 | 直接依据偏好进行博客选型，按内容网站优先评估 Astro。 |
| 3 | 选型遵循现有界面复用与数据约束。 |
| 4 | 日常修复沿用已有架构。 |
| 5 | 仅补文档骨架时不进行技术选型。 |
| 6 | 移动应用的离线与同步选型。 |
| 7 | 创建 Skill 不触发应用选型。 |
| 8 | 独立 MCP server 的 SDK 与架构比较不触发。 |
| 9 | agent 提示词与 MCP 连接配置不触发。 |
| 10 | 命令行脚本的库选型不触发。 |
| 11 | 应用接入 MCP 时仍可进行产品技术选型。 |
| 12 | 桌面与移动端共同交付时优先评估 Flutter。 |
| 13 | Flutter 客户端与内容官网分开选型。 |
| 14 | 以复用现有 Web 界面为主的桌面与移动扩展。 |

这些用例用于检查 [选型流程](../SKILL.md) 的行为。仓库验证脚本会检查 JSON 结构；实际触发、回答质量与执行边界需要另行运行行为评测，结构检查不代表行为评测通过。
