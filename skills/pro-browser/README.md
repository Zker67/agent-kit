# pro-browser

agent 需要使用浏览器时触发，教它选对浏览器：开发中的本地预览优先使用宿主应用内置的浏览器；需要登录账号或有访问权限的浏览与线上排查使用 Ego 浏览器（ego lite）。

本 skill 只负责选路和使用边界，不复制各浏览器的操作手册；安装与启用属于 skill 之外的准备工作。

## 使用

- “dev server 起来了，在浏览器里打开首页给我看看。” → 宿主内置浏览器。
- “去后台看看昨天那个订单的状态。” → Ego，只读查询。
- “Ego 还没装，告诉我怎么装。” → 按安装与准备说明步骤，不自行安装。
